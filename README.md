# Analyse-econometrique-des-determinants-de-l-acces-a-l-enseignement-superieur
L’orientation vers l’enseignement supérieur demeure un enjeu central des politiques éducatives. Pour cela, comprendre les déterminants individuels et familiaux de cette orientation permet d’identifier les leviers susceptibles de réduire les inégalités d’accès. 

L’objectif de cette étude est d’examiner l’influence du rendement scolaire (GPA), du capital éducatif des parents (pared) et du statut de l’établissement (public) sur la probabilité qu’un élève ait envie de poursuivre des études supérieures (apply), mesurée sur une échelle ordinale à trois modalités : peu probable, probable, très probable. Dans un premier temps, une analyse descriptive sera menée afin de mettre en lumière les grandes tendances du jeu de données. Dans un second temps, plusieurs modèles économétriques seront estimés pour identifier les variables les plus significatives et comprendre leur effet. 

Enfin, une section de diagnostics et de visualisations permettra d’approfondir l’interprétation du modèle retenu et d’évaluer la qualité des prédictions produites.
